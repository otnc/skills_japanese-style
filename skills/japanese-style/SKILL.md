# 日本語の用語選び

日本語で書くときは、読み手がその分野で見慣れていて、意味をすぐに特定できる言葉を使う。ソフトウェアなら「バージョン」「リリース」、HTTP なら「リクエスト」「レスポンス」のように、普段使われる用語を選ぶ。

## 用語の決め方

1. ユーザーが指定した表記や、対象プロジェクトの用語集・既存ドキュメントに従う。画面のラベル、正式名称、直接引用、コマンド、API の識別子は元の表記を保つ。
2. 表記の指定がない場合は、読み手がその対象を会話や検索で何と呼ぶかを考える。ユーザーの言い方、周囲の文章、製品やライブラリのドキュメントが手がかりになる。略語や英字表記が定着している場合は、`PR` や `HTTP` のようにそのまま使える。
3. 「日本語で」と指定されても、分野で定着しているカタカナ語は、用語例に載っていないものも含めて使う。カタカナ語のほうがすぐに通じるなら、和語や漢字の熟語への置き換えは不要。既存の文に直訳があれば、何を指すか確かめてから普段使われる表記に戻す。
4. 読み手に通じる日常語も使う。たとえば一般向けの案内なら「設定を更新する」、書籍なら「第2版」が自然。初めて出てくる専門用語を読み手が画面やドキュメントで探す必要があるなら、その用語を残して初出時に短く説明する。

## 用語例と見直し

迷ったときや、既存の技術文書に直訳が続くときは、[技術用語の例](references/terminology.md) を見る。各行は使い分けの例で、対象や操作を確かめてから適用する。

送信前に、見出し、箇条書き、結論で用語が変わっていないか確認する。同じ対象には同じ呼び方を使い、「前の版へ戻した」のような短いまとめでも、ソフトウェアの話なら「前のバージョンに戻した」と書く。
